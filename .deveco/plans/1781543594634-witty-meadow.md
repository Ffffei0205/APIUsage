# Goal

为 ApiUsage 项目实现华为官方 App 风格的 UI 界面，使用全部官方组件，展示所有 DeepSeek API 返回的余额信息，并提供 API Key 管理功能。

# Scope / Non-goals

**包含：**
- 底部 Tabs 双页面导航（余额主页 + 设置页）
- 余额主页：白色卡片式展示 `is_available`、`currency`、`total_balance`、`granted_balance`、`topped_up_balance`，蓝色强调色
- 设置页：API Key 输入框 + 持久化存储（使用已有 PreferenceManager）
- 首次进入无 API Key 时引导用户到设置页
- 修复现有代码的 ArkTS 合规问题（模板字符串、as 断言、saveValue bug）
- 在 EntryAbility 中初始化 UIContext 到 AppStorage
- 加载状态与错误提示

**不包含：**
- 新增 DeepSeek API 调用（如模型列表、用量查询等）
- 用户登录/注册
- 主题切换
- 国际化

# Current State And Constraints

## 现有代码问题
1. **DeepSeekApi.ets**：使用了模板字符串 `` `${...}` ``，ArkTS 不支持，需改为字符串拼接
2. **HttpUtil.ets**：使用了模板字符串和 `as` 断言，需修复
3. **PreferenceManager.ets**：`setValue()` 方法中 `this.saveValue` 缺少 `()`，持久化未生效
4. **Index.ets**：API Key 硬编码，UI 仅为简单文本+按钮测试页
5. **EntryAbility.ets**：未将 UIContext 存入 AppStorage，导致 PreferenceManager 初始化崩溃

## ArkTS 约束
- 不允许模板字符串，需用 `"str" + value.toString()` 拼接
- 不允许 `as` 断言，需用显式类型
- 不允许 `any`/`unknown`
- 不允许解构声明
- 对象字面量必须有显式类型上下文
- 不允许 `delete` 操作符

## SDK 版本
- targetSdkVersion: 6.1.0(23)
- 已申请权限: `ohos.permission.INTERNET`

# Design

## 页面结构

```
Index.ets (Tabs 底部导航)
├── TabContent: 余额主页
│   ├── 顶部标题区 (Text "API 用量查询")
│   ├── 无 API Key 提示卡片 (条件渲染)
│   │   └── 提示文字 + "前往设置"按钮
│   ├── 加载状态 (LoadingProgress)
│   ├── 错误提示 (Text + 重试按钮)
│   └── 余额卡片列表 (Scroll + ForEach)
│       ├── 状态卡片 (is_available 绿/红指示)
│       └── 每种货币余额卡片
│           ├── 货币标签 (如 "CNY")
│           ├── 总余额 (大字体蓝色)
│           ├── 赠送余额
│           └── 充值余额
└── TabContent: 设置页
    ├── 顶部标题区 (Text "设置")
    ├── API Key 管理卡片
    │   ├── 说明文字
    │   ├── 当前 Key 状态 (脱敏显示或"未设置")
    │   ├── TextInput (密码模式)
    │   ├── 保存按钮
    │   └── 删除按钮 (已有 Key 时显示)
    └── 关于卡片
        ├── 应用名称: ApiUsage
        └── 版本: 1.0.0
```

## 余额卡片布局

每个 `BalanceInfo` 渲染为一张卡片：
```
┌────────────────────────┐
│  CNY                    │  ← 货币标签，小字灰色
│                         │
│  ¥ 12.50               │  ← 总余额，大字体蓝色加粗
│                         │
│  赠送余额   ¥ 10.00     │  ← 两行分列显示
│  充值余额   ¥ 2.50      │
└────────────────────────┘
```

顶部还有一张状态卡片：
```
┌────────────────────────┐
│  ● 账户可用              │  ← 绿色圆点 + 文字
└────────────────────────┘
```
或
```
┌────────────────────────┐
│  ● 账户不可用            │  ← 红色圆点 + 文字
└─────────────────────────┘
```

## 状态管理

```
@State balanceResponse: BalanceResponse | null = null
@State isLoading: boolean = false
@State errorMessage: string = ''
@State apiKeyInput: string = ''         // 设置页输入框绑定值
@State savedKeyMasked: string = ''      // 脱敏 Key 显示
@State hasApiKey: boolean = false       // 是否有已保存 Key
@State currentTabIndex: number = 0      // 当前 Tab
```

`TabsController` 用于从余额页跳转到设置页（无 Key 时引导），以及保存 Key 后跳回余额页。

## API Key 存储流程

1. `aboutToAppear`：从 PreferenceManager 读取 Key → 设置 `hasApiKey` 和 `savedKeyMasked` → 如有 Key 自动查询余额
2. 设置页输入 Key → 点击保存 → PreferenceManager.setValue() → 更新状态 → 切换到余额 Tab → 触发查询
3. 删除 Key → PreferenceManager.deleteValue() → 清空余额数据和状态
4. Key 脱敏显示：取前4位 + "****" + 后4位

## 关键组件选择

| 需求 | 组件 | 说明 |
|------|------|------|
| 底部导航 | `Tabs` + `TabContent` | BarPosition.End |
| 卡片容器 | `Column` + .backgroundColor/.borderRadius/.padding | 白色圆角卡片 |
| 加载指示 | `LoadingProgress` | 官方组件 |
| Key 输入 | `TextInput` | type: InputType.Password |
| 按钮 | `Button` | .backgroundColor/#007DFF |
| 状态圆点 | `Text('●')` + .fontColor | 绿色/红色 |
| 滚动 | `Scroll` | 余额内容区 |
| 列表渲染 | `ForEach` | 遍历 balance_infos 数组 |

# Risks And Compatibility

- **SDK 6.1.0(23)**：Tabs、TextInput、LoadingProgress、Button 等组件在该版本稳定可用
- **rcp API**：HttpUtil 已使用 rcp，保持不变
- **PreferenceManager + UIContext**：需先在 EntryAbility 初始化 UIContext，否则 PreferenceManager 崩溃
- **BalanceResponse 可能为 null**：所有属性访问需做空判断
- **as 断言移除**：HttpUtil 中 `error as BusinessError` 需要改为其他方式获取错误码和消息
